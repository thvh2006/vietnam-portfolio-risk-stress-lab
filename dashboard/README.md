# Live dashboard

Static, dependency-free decision dashboard for the reviewed 30 September 2026 snapshot.

- Historical risk, stress and validation outputs are frozen to the Python engine results.
- Hedge sizing, residual beta, margin, approximate parametric VaR and exit time recalculate in the browser.
- The interactive layer is deliberately separated from the reviewed snapshot to avoid implying a live market-data feed.

Open `index.html` locally or use the public dashboard linked from the repository README.
